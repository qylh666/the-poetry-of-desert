# 角色头像目录

此目录存放角色档案库裁剪后的头像图片文件（**PNG**，每张 128×128）。

## 命名规范

文件名必须与角色的 `id` 一致，例如：

| 角色 id | 头像文件 |
|---|---|
| `islant` | `islant.png` |
| `eve` | `eve.png` |
| `antonio` | `antonio.png` |

## 使用方式

1. 在「角色档案库 → 更换头像」中选择图片并裁剪；
2. 页面会自动导出 `{角色id}.png` 并下载；
3. 把下载的文件放入本目录；
4. `forum/角色档案库.data.json` 的 `avatars` 字段只需记录相对路径（如 `avatars/islant.png`），**不再内嵌 base64 编码**，避免数据文件过大。

> 提示：也可以直接手动把任意 PNG 命名为 `{角色id}.png` 放入本目录，再在 data.json 的 `avatars` 里登记路径即可。
