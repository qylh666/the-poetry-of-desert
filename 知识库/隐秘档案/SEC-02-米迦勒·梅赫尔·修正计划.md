# SEC-02 米迦勒·梅赫尔·修正计划

> ⛔ L2 隐秘 | 知晓者：米迦勒、尼德霍格、耶梦加得、撒迦利亚（卧底）、安东尼奥（部分）；大陆大众完全不知梅赫尔存在 | 关联：NAT-07、ORG-06、ORG-08、HIS-04、CHR-34~37、CHR-42

## 一、三神的来历（神代余波）

- 诸神黄昏那天，作为发起战乱一方的神并未完全灭绝。将世界树根部啃食殆尽的毒龙**尼德霍格**逃离战场。
- 尼德霍格将挚友巨蛇**耶梦加得**的残余力量封印在从世界树割裂出的小岛上，并将自己与岛流放到一个少有人知的"异空间"——那里没有生命、不分昼夜，只有无尽寂静。
- 岛上封印着世界树的安保系统**米迦勒**，其任务是维护世界树完整性、消除威胁世界树运行的一切外部因素。
- 尼德霍格强制解除米迦勒的封印。启动后，米迦勒判定这个新世界完全不符合神之时代的世界树、需要被"修正"；这与尼德霍格一方"创造理想新世界"的目的相符，双方签订契约。
- 过度使用力量的尼德霍格陷入沉睡，等待米迦勒将祂与耶梦加得一起唤醒。
- 达成目的并不简单：如今的世界不适合神居住，大陆上还有流淌着创世神之血的沙漠神殿守护。米迦勒只能将异空间入口设置在始源岛，等待合适机会。

## 二、梅赫尔（组织与地区）

- 米迦勒为岛取名"**梅赫尔**"，创造人类化身**奥托**，让其从始源岛出发前往尤克特拉调查。奥托带回"火种"为神们的小岛带来光明；又带回各种知识，为后来苏醒的尼德霍格与耶梦加得提供消遣。
- **政治**：三位神共同统治；米迦勒为三神之主（秩序与教义），尼德霍格负责战斗训练与警戒，耶梦加得负责知识传承与居民精神抚慰；居民生活由三神直接安排，权力以神为绝对中心。
- **地理**：异空间小岛，原是世界树一部分，割裂后流放；岛上植被紫色系，照明来自米迦勒带来的火种；三神各有独立宫殿，风格各异，是标志性建筑。
- **人文**：居民多是从尤克特拉大陆逃亡而来的人。三神对居民都保持温柔：米迦勒如慈母教导秩序；尼德霍格言语严厉但从未真正伤害任何人；耶梦加得最随和、最受喜爱。生活氛围以崇拜与感恩为主：孩子们去尼德霍格训练场围观打架取乐，成年人轮流去耶梦加得处讲故事，米迦勒宫殿是定期聚集场所。紫色植被覆盖全岛，形成与外界截然不同的视觉与气息习惯，**居民对此习以为常，认为这是梅赫尔特有的美丽**。
- **最终目的**：米迦勒要"修正"世界（见 SEC-01·五）。

## 三、奥托、华城研究所与 C 计划

- 米迦勒让化身奥托在尤克特拉游历学习，并从中干扰战争；华城研究所的计划是其中一部分。
- **C 计划**：一项与"装载生命长河的本质信息"相关的机密研究（最终产物即伊芙，见 SEC-04）。
- 奥托认为时机已到时，以一场魔法大火"退场"：烧毁华城研究所、带走 C 计划的后期研究数据回到梅赫尔，回归米迦勒本体。
  - 后果：当年研究员无一幸存；幸存者沃特·梅林（见 SEC-03）；安东尼奥在火场救出 C 计划的一部分资料，后继续完成"晶体"制造。
  - 安东尼奥事后调查发现放火者是奥托，心情非常复杂。
- 玛格丽特当年受法协第一任会长要挟毁掉 C 计划资料，一切按奥托的计划进行（或许那场意外大火也是 C 计划的一环）——见 CHS-01。

## 四、撒迦利亚的卧底身份

- 暮色战争中，撒迦利亚被米迦勒（或其化身奥托）所救，被带到始源岛深处——那里有古老遗迹，启动后便成为梅赫尔的入口。
- 在梅赫尔听了米迦勒的演讲、住了一段时间，思想被"救世说"感化，决定成为米迦勒的剑、米迦勒在尤克特拉的卧底。
- 这发生在他成为圣殿骑士团团长之前。尤克特拉势力众多，米迦勒很少与撒迦利亚联系。
- 大众认知仅知"撒迦利亚是最后的红龙、圣殿骑士团团长"（CHR-11）。

## 五、暮色战争被延长的真相

- 战争进行多年后，即将结束的战火因**梅赫尔势力的插手**而被重新燃起，战争持续了百年之久（星陨 1350–1500）。
- 公开史只说"三国战火不断"（HIS-04），不提及梅赫尔。

## 六、密特拉与梅赫尔的真实关系

- 密特拉传说的"救赎之地"即**梅赫尔**的模糊投影；"圣天使"指米迦勒；"咏梦者"= 耶梦加得（守夜人在梦境中接收其低语）；"静默者"= 尼德霍格（守护者受其赐福）。
- 密特拉信徒不知梅赫尔全貌，只以信仰形式间接指向它（ORG-07/08）。
- 格拉西亚的"知心者"即圣天使/米迦勒（CHR-42）。
