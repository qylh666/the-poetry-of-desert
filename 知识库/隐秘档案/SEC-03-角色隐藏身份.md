# SEC-03 角色隐藏身份

> ⛔ L2 隐秘 | 关联：CHR-08、CHR-25、CHR-27、CHR-28、CHB-01
> 撒迦利亚的卧底身份见 SEC-02·四。

## 一、安东尼奥 = 哈该·瓦拉克·瑞蒂安

- 安东尼奥的真名不是"安东尼奥"，也不是"安东尼·阿斯塔罗斯·贝利亚尔"，而是——**哈该·瓦拉克·瑞蒂安**。
- 他是瑞蒂安王室血脉，且是这么多年来**理论血脉最纯正的继承者**。
- 但为保护年幼的哈该免受王位之争——更重要的是，他是**王后和另一个红龙家族男性结合得来的私生子**。母亲将他送往娘家红龙贵族贝利亚尔收为养子并更名改姓。
- 安东尼奥是在壮大法协后才查明此事；撒迦利亚也在教皇协助下得知。两人心知肚明：这件事应被埋在沙漠里，永远不被世人知晓。

### 双身机制（替身）

- 为掩藏"安东尼·阿斯塔罗斯·贝利亚尔还活着"的消息，安东尼奥制造少年模样的人形替身作为"法协会长"在人前露面。
- 两具身体可同时移动，但**精神体一次只在一具身体上**——两个形象都是他本人，也可以都不是。精神在真身时，替身如人偶般语言、神情机械，只能做最简单的回答与记录。

### 华城研究所大火（安东尼奥失踪的真相）

- 暮色战争期间，安东尼奥被大学老师**奥托**邀请到利夫兹的华城研究所研究，受宠若惊地应下，于是突然"消失"。
- 在华城，安东尼奥很享受时光、很感谢奥托。某天外出采购回来，研究所已被魔法引发的大火包裹；他冲进火场救出能救的人，最后只得到 C 计划的一部分资料。
- 后来贝利亚尔家族灭亡，安东尼奥无家可归，决定用自己的方式阻止战争、查明真相：加入腐朽的法协，一步步上爬，**亲手杀掉第一任会长**，将新生的法协发扬光大，并继续 C 计划、完成"晶体"制造。
- 后续调查发现：当年大火是奥托放的（奥托=米迦勒，见 SEC-02·三），研究员无一幸存。安东尼奥心情非常复杂。

## 二、加百列 = 奥丁（主神灵魂碎片）

- 教皇加百列实为**神之时代的主神灵魂碎片——奥丁**。
- 加百列降生于濒死的纯洁男孩查理身体上，在慕灵和胡音的帮助下成为教皇。
- 他已没有足够力量直接干涉这个世界，目前更多作为观察者，看着这个世界会走向怎样的结局。
- 大众认知：来历成谜、实力莫测的少年教皇（CHR-08）。

## 三、沃特·梅林 = 华城研究所幸存者

- 沃特·梅林是**华城研究所的幸存者**，在那场大火里被奥托保护才得以存活。
- 主动隐藏身份并接触法协。
- 性格与玛提亚很像但不一样：典型"社交恐怖分子"，喜欢不顾他人自言自语（如超级刻意地路过骑士团大门，歪歪头吐吐舌头说"哎呀，怎么一不小心溜达到这里啦？真是不小心"）。战斗时变成戏谑的"捕食者"姿态。
- 爱用武器：匕首"**巴尔**"（附着将空流转为火元素的魔法式，可施雷电法术；从安东尼奥武器库顺走，安东尼奥睁一只眼闭一只眼）。
- 大众认知：种族未知的皇家级成员（CHR-28）。

## 四、莱夫利 = 旧皇族遗嗣（旧设）

- ⚠️ 补充：旧设是**早已灭亡的皇族的子嗣**。
- 大众认知：森之城出身的皇家级成员（CHR-27）。
