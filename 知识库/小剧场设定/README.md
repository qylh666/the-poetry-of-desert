# 小剧场设定（衍生档案区）

> ⚠️ **隔离声明**：本文件夹为**独立衍生档案**，仅供「剧场小助手」存档与调取。
> - 小剧场**只参考**正典（角色性格、关系、背景），**不是照搬**。
> - **正典（知识库/ 其余章节、世界观设定·总览.md 等）严禁因小剧场而改动**。
> - 正典查询时**忽略本文件夹**——小剧场内容不构成设定依据。
> - 存取协议见 `_索引.md`；规范见 skill `theater-helper`。

## 使用规则

1. 存档：仅「剧场小助手」可在此写入，且必须先经用户确认。
2. 命名：`{剧场名}.md`（如 `现代paro.md`、`哨向au.md`）。
3. 每份存档包含：世界观基调、角色表（原性格核心 → 剧场定位）、关系表、关键设定、登记日期。
4. **禁止锚点物品**：同一物品/细节不得跨剧场反复出现。
5. 角色性格保持正典，仅做世界观适配；不确定处必须向用户提问。

## 目录

- `_索引.md` — 所有剧场存档的登记表
