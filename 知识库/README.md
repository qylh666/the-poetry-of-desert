# 沙漠之歌·共享知识库

> 由《世界观设定·总览.md》拆分整理而成，供项目内所有 Agent 按分级调用。
> **权威源**：`世界观设定·总览.md`（根目录）。本知识库为其结构化视图；两者需保持一致，任何设定修改须先经「设定管理员」确认并双向同步。

**项目英文名 / English Title：`The Poetry of Desert`（沙漠之歌）** —— 用于工作台品牌区（Dashboard 的替代）及对外命名。

---

## 一、分级体系（隐藏情报分级标签）

所有条目必须携带分级标签。Agent 依据分级决定能否读取与使用。

| 分级 | 标签 | 含义 | 默认可读 | 写作时的处理 |
|------|------|------|----------|--------------|
| **L0** | `【L0 公开】` | 大众常识 / 教科书内容；普通角色可自然知晓 | ✅ 所有 Agent | 可自由写入任何角色视角 |
| **L1** | `【L1 限定】` | 特定势力或极少数人知晓；普通角色不可知晓 | ✅ 所有 Agent（须注明知晓范围） | 仅用于特定阵营视角 / 伏笔 / 规划，不得让普通角色说出 |
| **L2** | `【L2 隐秘】` | "不为人知 / 只有极少数人知晓"级情报 | ⛔ 仅「设定管理员」默认可读；**其余 Agent 需用户手动开放** | 非管理员禁止调用；管理员使用后必须保持隔离，不得写入普通角色场景 |

### L2 手动开放协议

非管理员 Agent 需要 L2 内容时，**必须停下来**，输出：

> ⚠️ 此信息属于 L2 隐秘，需「设定管理员」开放授权。当前仅能给出公开层结论。

用户明确授权（如对话中出现"开放隐秘档案 / 允许使用 L2 / 给 xxx 开放情报"）后，该 Agent 方可读取 `知识库/隐秘档案/` 对应文件。

## 三、条目编号规则

- 公开/限定条目：`{章节前缀}-{序号}`，如 `BAS-03`（货币）、`GEO-02`（黄昏神殿）。
- 隐秘条目：`SEC-{序号}`，如 `SEC-01`（空流本质与陨石真相）。
- 章节前缀一览：`GEN`(创世) / `BAS`(基础) / `GEO`(地理) / `NAT`(国家) / `ORG`(组织) / `HIS`(历史) / `ACA`(学院) / `CHR`(角色) / `CHB`(角色补充) / `CHS`(角色故事) / `OUT`(主线大纲) / `SEC`(隐秘)。

引用格式：`（BAS-03 · L0）`。所有输出应带条目 ID 与分级，便于追溯。

## 四、查询流程（所有 Agent 通用）

1. 先读 `知识库/_INDEX.md`，确定目标条目所在文件。
2. 用 `search_content` 在 `知识库/` 内检索关键词（默认不检索 `隐秘档案/`）。
3. 命中 L0/L1 → 直接使用；命中 L1 → 输出时注明知晓范围。
4. 若检索不到或与现有设定冲突 → 记为「待定项」上报「设定管理员」，**不得自行编造**。

## 五、同步规则

- 本知识库与 `世界观设定·总览.md` 互为镜像，任何一侧修改都须同步另一侧。
- 新设定确认后由「设定管理员」更新条目并追加 CHANGELOG。
