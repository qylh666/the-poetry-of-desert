# 沙漠之歌 · 创作与设定工作台

> **The Poetry of Desert** — 原创奇幻世界观《沙漠之歌》的设定管理与创作辅助工具。

一套**纯静态 HTML 工作台**，用于管理《沙漠之歌》世界观的势力、角色、历史、地理、术语与星历，并支持在手机/平板浏览器上翻阅与轻量编辑。

---

## ✨ 功能一览

| 模块 | 说明 |
|---|---|
| 🏠 欢迎页 | 今日日期备注（节日/生日联动）、今日人品小游戏、模块入口 |
| 🍺 酒馆 | 市井告示板 / 传闻 / 朋友圈 / 小手机合集 |
| 📅 星历 | 尤克特拉日历：凯旋日等节日、角色生日（自动联动）、自定义事件 |
| ⚔️ 势力与阵营 | 树形层级 + 详情面板 + 关系网三区布局 |
| 📜 历史事件 | 星陨纪年时间线，支持分级（L0/L1/L2）与隐秘真相 |
| 🗺️ 地理总览 | 大陆地图与地区设定 |
| 📖 术语库 | 世界观辞典：空流、魔法式、晶体、五大元素等 |
| 👥 角色档案库 | 卡片墙 + 关系网（树状/方形/圆形排列、画布拖拽、间距调节）、头像裁剪 |

## 📁 目录结构

```
├─ index.html                  # 网页入口（自动跳转工作台）
├─ 工作台/                     # 工作台页面
│   ├─ 开始页.html
│   ├─ 功能模块/               # 酒馆、日历
│   └─ 设定资料/               # 势力、历史、地理、术语、角色档案
├─ forum/                      # ★ 数据与素材（核心资产）
│   ├─ *.data.json             # 世界观数据（角色/势力/历史/术语/日历…）
│   ├─ avatars/                # 角色头像图片
│   └─ standalone.js           # 网页部署降级层（见下）
├─ 知识库/                     # 创作参考与分级情报（L0/L1/L2）
├─ 参考/                       # 世界观设定总览与模块模板
└─ CHANGELOG.md                # 变更记录
```

> `forum/` 是**数据的唯一事实来源**，页面全部通过相对路径读取，改数据即改页面内容。

```
手机网页编辑 → 导出 JSON → 传回电脑放回 forum/ → 完成同步
```

⚠️ 注意事项：
- localStorage 按浏览器独立，**换设备/清缓存会丢失**，请养成导出习惯
- 头像裁剪在网页端输出 PNG 文件，建议头像在电脑端处理
- 双端错峰编辑，避免文件冲突

## 🛠️ 技术说明

- 纯原生 HTML + CSS + JavaScript，无构建步骤、无依赖（字体走 Google Fonts 外链）
- 数据驱动：所有内容存于 `forum/*.data.json`，页面动态渲染
- 双环境兼容：`forum/standalone.js` 自动检测 Spherse 环境，原生保存与本地存储无缝切换
- 亮色/暗色主题：白 + 宝蓝 / 暗色 + 鎏金，全站 CSS 变量驱动，一键切换
